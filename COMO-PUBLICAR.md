# Como hospedar a NEON Store no GitHub

1. Entre no GitHub com a conta **Thiiaguinho06** e acesse o repositório já criado: https://github.com/Thiiaguinho06/Thiiaguinho06-NEON-Store-E-commerce-de-tecnologia.
2. Clique em **Add file > Upload files** (ou **uploading an existing file**) para enviar o projeto, se o repositório estiver vazio.
3. Extraia o ZIP e envie **todos os arquivos diretamente na raiz** do repositório. Não é necessário criar a pasta `assets`: `index.html`, `script.js`, `styles.css` e todas as imagens `.svg` ficam no mesmo nível.
4. Em **Settings > Pages**, selecione **Deploy from a branch**, `main` e `/(root)` e clique em **Save**.
5. Abra o link exibido pelo GitHub Pages após a publicação. O endereço seguirá o formato `https://USUARIO.github.io/neon-store/`.
6. Configure o link em **About** e acrescente os tópicos `html`, `css`, `javascript`, `ecommerce`, `frontend`, `localstorage`, `responsive-design`.
7. Teste busca, filtros, favoritos, carrinho, cupom `DEV10` e checkout de demonstração no desktop e celular.

**Atenção:** o erro 403 ao usar `git push` é um problema de permissão da conta GitHub autenticada e não é corrigido por mudar as pastas. No site do GitHub, envie os arquivos logada na conta proprietária do repositório ou como colaboradora autorizada.
